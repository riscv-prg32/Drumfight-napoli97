character names are Neapolitan/Italian.

## Repository layout

```text
src/df_core.h            rules: pattern, judge, moves, CPU, network packing (no PRG32 calls)
src/drumfight.c          the cartridge: states, sequencer, input, audio, drawing
audio/                   drum kits: eight PCM one-shots and audio.json (generated by tools/build_audio.py)
metadata/                Store metadata and colophon (single source of truth)
assets/store/            icon, screenshot, 30-second preview
tests/                   host tests (logic and full gameplay) and their PRG32 host layer
tools/                   generators and validators
scripts/                 build, bundle, host checks, QEMU capture
dist/                    released cartridges, Store bundle, checksums
docs/                    this documentation
```
